Create a token

A token can create and update courses, set rosters (creating accounts) and read results. Treat it like an administrator password.

Instant grade updates

When a grade changes (a test is submitted or finished grading, an answer key is corrected, a score is overridden, an answer sheet is scanned), Scholar tells the other system straight away, so its gradebook is current within seconds. The RosarioSIS plugin sets this address up by itself when you save its settings. If it can't be reached, Scholar tries again for hours, and the plugin also asks for missed changes every minute.
